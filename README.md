# NeoGBC — Emulador de Game Boy & Game Boy Color para Android

Emulador de **Game Boy (DMG)** e **Game Boy Color (CGB)** para Android com suporte a 120Hz, áudio estéreo APU de 4 canais, Save States com miniatura, biblioteca de jogos, filtros visuais e editor de controles virtuais na tela.

---

## 📲 Instalação Rápida no Celular (Sem precisar compilar)

O instalador pronto (**`NeoGBC.apk`**) já está incluído diretamente na raiz deste repositório:

### Opção 1 — Baixar apenas o APK direto pelo GitHub (Mais fácil)
1. Na lista de arquivos do repositório aqui no GitHub, toque no arquivo **[`NeoGBC.apk`](./NeoGBC.apk)**.
2. Toque no botão **Download raw file** (ícone de seta para baixo `⬇` ou menu `...` → **Download**).
3. Abra o arquivo `NeoGBC.apk` baixado no seu celular Android e confirme em **Instalar**.

### Opção 2 — Se você baixou o código em `.ZIP`
1. Extraia o arquivo `.zip` baixado do GitHub no gerenciador de arquivos do seu celular.
2. Logo na pasta principal extraída, toque no arquivo **`NeoGBC.apk`** para instalar o aplicativo.
*(Se o Android solicitar permissão para instalar apps daquela fonte, ative a chave e confirme).*
